# BGTech Store — site institucional / vitrine

Site estático pronto para publicação em Netlify, Vercel, GitHub Pages ou hospedagem convencional.

## Publicação rápida no Netlify
1. Acesse https://app.netlify.com/drop
2. Arraste a pasta do projeto (ou o ZIP extraído) para a área indicada.
3. O Netlify gera um endereço provisório imediatamente.
4. Em Domain management, conecte o domínio próprio quando estiver disponível.

## Publicação rápida no Vercel
1. Crie um repositório com estes arquivos ou importe o projeto na Vercel.
2. Não há comando de build: o projeto é HTML/CSS/JS puro.
3. O diretório de saída é a raiz do projeto.

## Antes de usar domínio próprio
Edite em index.html, robots.txt e sitemap.xml o endereço `https://bgtechstore.com.br/` caso o domínio final seja diferente.
